## How to Navigate This Project

### Color/Tag Legend (apply in Unity Inspector):
- **Green/Ready**: Fully functional, ready for art pass
- **Yellow/WIP**: Works but needs iteration/polish
- **Red/Placeholder**: Temporary greybox - replace with real art
- **Blue/Generated**: Created at runtime - don't manually edit these in scene

## Quick Start for Artists:

1. **Open:** `SimpleNaturePack_Demo.unity`
2. **Find:** `Map/Stations/` folder in Hierarchy
3. **Replace:** Station button sprites (currently colored boxes)
4. **Add:** NPC sprites to `VipMarkerUI` prefab (male/female)
5. **Customize:** Route line colors in `MapVisualizer` Inspector

**Don't touch:**
- Scripts
- GameManager/TrainMover
- Anything marked [RUNTIME]

**Safe to edit:**
- Sprite assets
- Colors/materials
- UI layout (positions, sizes)
- Parallax layer textures
